# PocketGym · 健身速记 3.5

适合手机使用的个人健身记录工具：按组记录重量与次数、四组方格、常用动作收藏、力量/有氧记录、训练历史和数据导出。

## GitHub Pages 部署

在此仓库的 **Settings → Pages → Build and deployment** 设置：

- **Source**: Deploy from a branch
- **Branch**: main
- **Folder**: /(root)

保存后，站点地址为 `https://bluesea405.github.io/Gym/`（注意仓库名称大小写）。

iPhone Safari 打开站点后，选择“分享 → 添加到主屏幕”即可安装快捷方式。

> 数据默认储存在当前浏览器的本地存储，不上传到 GitHub，也不会自动跨设备同步。建议定期导出 JSON 备份。

## 3.5 按计划打卡

首页增加上肢 A、下肢 A、上肢 B、下肢 B 四个预置训练日；开始后按动作顺序记录，每一项填写重量和次数后点击「保存并下一步」，会自动载入下一项。可以跳过、返回、恢复进度。原有训练历史数据结构与 LocalStorage key 不变，计划进度单独存储。

## v3.5：自定义训练模板与紧凑首页

- 四套预置 Upper / Lower 训练日可增删动作、修改组数 / 目标次数 / 休息时间、手机端使用 ↑ ↓ 排序，可恢复默认。
- 可复制任意训练模板，创建自定义训练日；模板和训练进度仅保存在本机，并可通过 JSON 备份 / 导入。
- 修改模板不会改动正在执行中的训练（每次开始计划会冻结当次动作清单）。
- 首页优先显示训练计划 / 当前动作，动作列表、统计、训练记录和操作说明默认可折叠。
- 计划训练底部固定「保存并下一步」按钮，便于单手记录。

升级保留历史记录 key `pocket_gymlog_v1`、收藏 key 和进行中计划 key `pocketgym_active_plan_v33`，不清除已有浏览器数据。

## 3.5 · iOS 风格界面更新

- iOS 风格浅色与深色自适应（随系统），简洁卡片、原生感的底部导航与移动端排版。
- **严格保留原有 Excel 式训练方格**：每列一组，第一行填写重量（kg），点选下方次数格；默认 4 组整行显示，增加到 5 组以上时支持横向滑动。前端记录数据及处理逻辑未改。
- 首页突出今日计划和当前动作；训练概览、完整动作清单、模板编辑和历史记录按需展开。
- 保留原有 localStorage 键 `pocket_gymlog_v1`、`pocketgym_favorites_v3`、`pocketgym_active_plan_v33`、`pocketgym_templates_v34`，原数据无需迁移。
